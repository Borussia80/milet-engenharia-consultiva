# MILET Engenharia Consultiva

Site institucional estático. A branch `main` publica a página atual em `milet.com.br` via GitHub Pages.

## Versão de revisão do design system

A branch `feat/milet-design-system` aplica a identidade visual fornecida para revisão. Os arquivos de marca, tokens e fonte estão em `assets/milet/`. O FOCA aparece como ilustração estática na seção de contato; não há chatbot.

Antes de lançar esta versão, definir e verificar um canal comercial funcional, revisar o escopo dos serviços e testar visualmente em telas grandes e pequenas. O site não contém formulário nem promete um prazo de resposta. A migração para Cloudflare e o DNS são trabalhos separados.

Os arquivos Montserrat foram fornecidos no pacote da marca; a licença SIL OFL correspondente está em `assets/milet/fonts/OFL.txt`.
